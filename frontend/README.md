# DevTrack AI Frontend 🚀

This is the frontend of DevTrack AI, a MERN-based bug tracking system.

## Live Link

https://devtrack-ai-delta.vercel.app

## Features

- User Authentication (Login/Register)
- Protected Routes
- Dashboard with analytics
- Project management
- Bug tracking system
- Status updates (Open → In Progress → Closed)
- Responsive UI using Tailwind CSS

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Axios
